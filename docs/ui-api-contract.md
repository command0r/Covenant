# Console ↔ Host API contract (UI implementation, 2026-10-16)

Authoritative for the Blazor console. Existing endpoints keep their shapes unless listed as changed.
Admin endpoints take `X-Covenant-Admin-Token`. Application endpoints take an application key
(`Authorization: Bearer <key>` or `x-api-key`). The two are never interchangeable.

## Correlation (Task 02)
- Every response under `/v1/*` carries `X-Covenant-Request-Id: req_<32 hex>`, generated by Host
  middleware before binding, so even a malformed body (400 from binding) carries it. The same value is
  `id` in the buffered OpenAI response, the Anthropic message `id`, `request_id` in error bodies, and
  **`Id`** of the audit record. Audit `Id` == correlation id (one identity; `CorrelationId` field is a
  duplicate for explicitness).
- Streaming: header is on the SSE response (committed with the 200). Mid-stream failure keeps HTTP 200;
  the final outcome is in the audit record (`Effect=Deny`, `DenialKind=UpstreamFailure`).
- Requests that fail JSON binding never reach the pipeline and have **no audit record**; the UI shows
  "rejected before governance (400); no evidence record" for that case.

## Audit record v2 (Task 02/03) — additive, hash-compatible
Legacy lines verify unchanged (the chain hashes the stored bytes; new fields are nullable and absent on
old records → UI renders **Not recorded**).
```
SchemaVersion           int      2 (absent/1 on legacy)
CorrelationId           string?  == Id
ClassificationEvaluated bool?    false when a stage before Classify denied (Classification is then the
                                 restrictive default and must be shown as "Not evaluated")
DenialKind              string?  None|Governance|UpstreamFailure|Unauthenticated|RateLimited|Unsupported|Cancelled
StoppedAtStage          string?  auth|shape|policy|cache|rate_limit|pause|budget|provider|attribution|null(completed)
SelectedModel           string?  policy's chosen route model (may exist on a denial)
AttemptedModel          string?  a provider call was actually started for this model
ServedByModel           string?  (existing) response produced by this model (cache hit: the cached model)
Stream                  bool?
UsageReported           bool?    provider returned token counts (false ⇒ tokens are NOT a real zero)
CostBasis               string?  reported|estimated_from_text|no_call|unpriced
```
`CostBasis=estimated_from_text`: priced model, no usage reported → cost estimated from chars/4 and
**charged to the budget** (fail-closed). `unpriced`: model with no price entry → cost 0 but flagged;
aggregates must count it as unknown, never as $0 saving. `no_call`: refusal/cache hit, a real zero.

## Admin lookups (Task 02)
- `GET /admin/requests?limit=200` → `{ "segment": {"path","entries","chain_valid","first_utc","last_utc"},
  "items": [AuditEntry…] }` newest first, max 1000, **current audit segment only** (since last archive).
- `GET /admin/requests/{id}` → 200 AuditEntry | 404 `{ "error":"not_found", "scanned": n }`. The UI treats
  404 as "pending" for a bounded time after its own request (sink is async), then "unavailable".

## Catalog & providers (Task 06)
- `GET /admin/catalog` → `{ "mode":"cloud|local-only", "models":[ { "adapter","model_id","classifications":[…],
  "registered":bool, "price_basis":"configured|zero|unpriced", "in_per_1m","out_per_1m",
  "endpoint_host":"host:port|null", "health":{"state":"unknown|ok|failed","last_success_utc","last_failure_utc","last_error"} } ],
  "local": { "configured":bool, "endpoint":"scheme://host:port|null", "model_id", "registered":bool } }`
  Health is observed from real pipeline calls and admin probes; `unknown` until observed.
- `POST /admin/providers/probe` `{ "endpoint": "http://host:11434/v1" }` → `{ "allowed":bool, "reachable":bool,
  "http_status", "models":[tags], "error", "duration_ms", "endpoint":normalized }`. Allowed destinations =
  `Providers:ProbeAllowList` (host[:port] list) ∪ configured `Local:Endpoint` host. 5 s timeout, 64 KiB cap,
  no redirects, http/https only. Never forwards Covenant tokens.
- Startup mode `Providers:Mode` = `cloud` (default; requires OpenAI:ApiKey) | `local-only` (requires
  Local:Endpoint + Local:ModelId; no cloud key; Public/Internal route to the local model). ADR-0010.

## Status additions (Task 07)
`/admin/status` gains `environment`, `mode`, `audit_path`, `cache_ttl_seconds`, `prompt_preview_chars`,
`anchor:{configured, every, anchors_written, last_anchor_utc}`, `version`. `/admin/evidence` gains
`anchor_configured`, `anchor_count`, `last_anchor_utc`. Nothing in status is a secret.
